# MOB-05 — Responsive login и полный admin

> **Для goal mode:** REQUIRED SUB-SKILL: сначала применить `superpowers:executing-plans`; browser-проверки выполнять через `playwright`. Выполнить только `MOB-05`. Коммит, смена ветки, начало `MOB-06` запрещены.

**Goal:** сделать login, SuperAdmin management и все встроенные content/media CRUD controls/forms пригодными на 320, 375, 768 и 1024 px, сохранив desktop 1440 px и существующие API/business contracts.

Использовать shared responsive form styles, минимальные semantic JSX-изменения и feature-scoped placement admin controls. ## Границы и зафиксированные решения

### Scope

- `/admin`: login, loading, validation/error, success, refresh, logout.
- `/admin/basic-admins`: list, add, edit login/password, delete.
- Все существующие News, Schedule, Group, Member, Social, Music, Footer social и Video CRUD forms.
- Все встроенные add/edit/delete controls на public pages.
- File inputs для JPEG/PNG/WebP/MP4.
- Touch targets, compact layout, scrollability, validation visibility.
- Viewports 320/375/768/1024; landscape 812×375; desktop regression 1440.
- Device E2E, screenshots, evidence и implementation state.

### Вне scope

- Новая admin dashboard.
- Новые CRUD/API contracts, backend architecture, schema или migrations.
- Dependency updates и глобальный Bootstrap CSS import.
- Переписывание alert/error architecture всех старых content forms.
- Общий accessibility/reduced-motion/alt/contrast audit `MOB-06`.
- Исправление двух известных QA-03 ESLint errors.
- Production DB, Blob, API, credentials или deployment.
- Wiki write: AGENTS требует отложить Wiki sync, пока evidence uncommitted.
- Любая задача после `MOB-05`.

### Locked UI decisions

- `<=1024px`: формы занимают доступную ширину modal body; labels, fields, validation и actions складываются вертикально.
- `<=768px`: form groups и action buttons имеют `width:100%`; controls минимум `44px` высотой; file input не создаёт overflow.
- Basic Admin table:
  - `>768px`: обычная semantic table;
  - `<=768px`: `thead` скрыт визуально, каждая `tr` показана карточкой;
  - `td[data-label]` показывает подписи `ID`, `Логін`, `Дії`;
  - edit/delete actions складываются без horizontal scroll.
- Одна table, один state, один набор controls. Отдельный mobile component не создавать.
- Icon-only admin controls всегда доступны touch/keyboard, имеют Ukrainian `aria-label` и минимум `44×44px`.
- Footer admin controls всегда существуют в DOM: desktop показывает их через hover/focus, compact показывает постоянно. Mouse-only `hoveredIndex` удалить.
- Desktop 1440 geometry/colors/frame сохранить. Новые desktop изменения ограничить admin readability; весь сайт не рестилизовать.
- Existing validation contract сохранить. Native required/type checks, shared `ValidationErrors` и существующие alerts должны быть видимы и доступны внутри compact modal.
- Публичные API, DTO, context signatures и routes не менять.
