# MOB-02 — Responsive Home, News и Schedule

> Для goal mode: сначала применить `superpowers:executing-plans`; browser-проверки выполнять через `playwright`. Выполнить только `MOB-02`. Коммит, смена ветки и начало `MOB-03` запрещены.

**Цель:** сделать Home, News и Schedule полностью usable на 320, 375, 768 и 1024 px без изменения business/API contracts и без регрессии desktop 1440 px.

**Архитектура:** сохранить текущие React contexts, маршруты, Swiper и CRUD flows. Адаптацию выполнить page-scoped React/SCSS-изменениями; shared pagination менять только через opt-in mobile mode для News/Schedule. `style.scss` остаётся canonical source, `style.css` и map генерируются существующей командой.

**Tech stack:** React 18, TypeScript 5.6, Swiper 11, React Bootstrap, Sass 1.79.6, Vite 6.

## 1. Зафиксированные границы и решения

### Preflight facts

- `MOB-02` существует, статус `planned`.
- Единственная зависимость `MOB-01` имеет статус `done`.
- Активен milestone `M3`.
- Корневого `AGENTS.md` на диске нет; обязательны инструкции текущего запроса и `frontend/AGENTS.md`.
- Worktree уже dirty. В частности, пользовательские изменения есть в `PromotionVideoHome.tsx`, generated `style.css`/map, backlog/state/index и многих несвязанных файлах.
- Считать весь стартовый diff пользовательским. Не откатывать, не форматировать, не перезаписывать его.
- Субагенты не использовать: React/SCSS/generated CSS образуют одну линейную область изменений.

### Scope

- Home responsive grid, Home Swiper, touch-visible cards, section states.
- News responsive grid, semantic card activation, pagination, long titles/dates.
- Schedule responsive grid/cards, long titles/location/status.
- Внутреннее содержимое News/Schedule detail: responsive text/media/map.
- Add/edit/delete trigger placement и доступность; только открытие существующих modal/form flows.
- Loading, empty, error, retry и long-content fixtures.
- 320/375/768/1024 plus desktop 1440 evidence.
- Generated runtime CSS, evidence и implementation state.

### Вне scope

- Business logic, contexts, DTO/models, API/backend, DB/Blob, migrations.
- Отправка CRUD mutations и адаптация самих admin forms: `MOB-05`.
- Outer modal sizing, focus trap, Escape, scroll lock: `MOB-04`.
- Music/Group/Video page layouts: `MOB-03`.
- Полный accessibility/cross-browser audit: `MOB-06`.
- `prefers-reduced-motion`, полный ESLint baseline: `MOB-06`/`QA-03`.
- Dependency updates, redesign desktop, production access.

### Выбранный подход

1. **Выбран:** текущий DOM + responsive SCSS + минимальные semantic React changes. Минимальный diff, сохранение architecture и desktop.
2. Не использовать viewport-specific React trees: дублируют content/state и повышают риск расхождения.
3. Не вводить новую grid/carousel/UI library: scope и dependency update не обоснованы.

Приняты рекомендуемые defaults, поскольку выбор пользователя не получен:

- Home при `<=768px`: `Schedule → News → Promotion video`.
- Home при `769–1024px`: News занимает верхний ряд; Video и Schedule — второй ряд.
- News/Schedule: 1 колонка на 320/375, 2 на 768, 3 на 1024 через `auto-fit/minmax`.
- Swiper: 1 slide по умолчанию, 2 от 640 px, 3 от 1024 px. Swiper 11 официально поддерживает `breakpoints` для `slidesPerView`/`spaceBetween`; dependency не менять.
- На compact карточках текст видим постоянно, не только при hover.
- В News/Schedule compact-card full title/location/status переносятся без clipping; Home teaser разрешено ограничить тремя строками.
