# MOB-01 — Responsive foundation и единый SCSS workflow

> Для goal mode: сначала применить `superpowers:executing-plans`; для viewport/screenshots — `playwright`. Выполнить только `MOB-01`. Commit, смена ветки, следующая backlog-задача запрещены.

## Summary

**Цель:** убрать системный desktop-only layout, сохранив desktop-визуал и создав основу для последующих mobile-задач.

**Зависимости:** `FEAT-03`, `FEAT-04`, `FEAT-05`, `FEAT-06`, `FEAT-07`, `FEAT-08`, `FEAT-09`, `FEAT-10`, `API-04` имеют статус `done`. Если при повторной проверке хотя бы одна зависимость не `done` — остановиться без изменений.

**Scope:**

- глобальные размеры `html/body/root/app/frame`;
- responsive frame composition;
- Header, burger/drawer, Footer;
- breakpoints `768px` и `1024px`;
- SCSS как canonical source, генерация runtime `style.css`;
- browser evidence 320/375/768/1024/1440;
- evidence и implementation state.

**Вне scope:**

- responsive grids Home/News/Schedule (`MOB-02`);
- Music/Group/Video (`MOB-03`);
- modal/media/state accessibility (`MOB-04`);
- login/admin forms/tables (`MOB-05`);
- полный keyboard/focus/reduced-motion/cross-browser audit (`MOB-06`);
- business/API/backend/DB/Blob изменения;
- desktop redesign;
- исправление существующего ESLint baseline;
- миграция всего SCSS с `@import` на `@use`;
- production access.

Субагенты не использовать: изменения образуют одну последовательную style pipeline и затрагивают общие CSS sources.

## Locked implementation decisions

### Responsive layout

- `>1024px`: сохранить существующий SVG frame, desktop grid `86% / 14%`, расположение Header/Footer и фактический runtime-визуал.
- `<=1024px`: скрыть декоративный SVG, перейти на одноколоночный document-flow layout.
- Порядок compact layout: Header, page content, Footer.
- `<=1024px`: desktop nav links скрыты, burger/drawer включён.
- `<=768px`: уменьшены logo/padding/drawer dimensions; touch controls минимум `44×44px`.
- Не скрывать дефекты глобальным `overflow-x: hidden`; устранять реальные источники ширины.
- Feature-specific clipping не исправлять. Диагностировать и отнести к `MOB-02`, `MOB-03` или `MOB-05`.

### Style workflow

- Canonical source: `src/styles/style.scss` и импортируемые `.scss` partials.
- Runtime artifact: tracked `src/styles/style.css` и `style.css.map`, генерируемые только npm-командой.
- Добавить exact dev dependency `sass@1.79.6`.
- Причина версии: `@import` deprecated начиная с Sass 1.80; полный `@use` migration слишком широк для MOB-01. Версия 1.79.6 — последняя перед deprecation warning, без suppression diagnostics. См. [официальное объявление Sass](https://sass-lang.com/blog/import-is-deprecated/) и [npm versions](https://www.npmjs.com/package/sass?activeTab=versions).
- Добавить scripts:

```json
"styles:build": "sass --style=expanded --source-map src/styles/style.scss src/styles/style.css",
"predev": "npm run styles:build",
"prebuild": "npm run styles:build"
```

- `dev` и `build` сохраняют текущие команды; lifecycle hooks гарантируют генерацию CSS.
- Legacy per-partial `.css/.map` не удалять: это будущий `CLEAN-01`.

### Interfaces

Публичные React/API/types interfaces не меняются.

Новые внутренние interfaces:

```scss
$layout-mobile-max: 768px;
$layout-compact-max: 1024px;
```

```bash
npm run styles:build
```
