> **Для выполнения в новом goal-mode чате:** сначала прочитать актуальные AGENTS.md и источники истины из раздела «Подготовка», затем использовать навык superpowers:executing-plans и выполнять checkbox-шаги последовательно. Инструкции этого плана запрещают commit, переключение ветки и начало MOB-01.

**Цель:** удалить placeholder с /developers, сохранив намеренно пустую статическую страницу внутри общего layout и работоспособность прямой SPA-ссылки.

**Стек:** React 18, TypeScript 5.6, React Router 7, React Helmet Async, Vite 6, Azure Static Web Apps route configuration.
